# 分组管理功能-交互设计文档

## 1. 产品概述

### 1.1 产品定位
Little Ice 是一款桌面端 AI 对话管理工具，专注于帮助用户管理多主题对话、收藏高价值内容、并通过角色模板定制 AI 回复风格。

### 1.2 核心用户场景
- 与 AI 进行多轮对话，管理多个对话主题
- 收藏 AI 回复中的高价值内容，沉淀为个人知识库
- 通过角色（Role）模板定制 AI 的回复风格

## 2. 设计原则

本设计遵循以下核心原则：

- **尼尔森十大可用性启发式**：系统状态可见性、一致性、用户控制与自由等
- **Fitts's Law**：关键操作目标（Tab 按钮、新建分组）尺寸充足，易于点击
- **Hick's Law**：MVP 阶段保持简洁，选项数量控制在 4 个 Tab 以内
- **内观一致性**：所有资源类型（对话/收藏/角色）采用完全相同的交互模式
- **系统状态可见性**：所有操作均有即时的视觉反馈

## 3. 分组管理布局架构

```

| 小冰                          [☰ 收起]     |  ← 顶部 Header（52px）
```

| 底部 Tab Bar | 58px | #FFFFFF | 四个 Tab 切换按钮 |

### 3.2 窗口规格

- 高度：720px（固定高度，模拟桌面应用窗口）
- 圆角：28px（外层容器）
- 阴影：`0 20px 40px rgba(0,0,0,0.08), 0 6px 12px rgba(0,0,0,0.05)`

## 5. 组件设计规范

### 5.1 顶部 Header

**结构**
```
[品牌名 "小冰"]      [☰ 收起按钮]
```

**交互**
- 品牌名：不可点击，仅展示
- 收起按钮：点击切换底部 Tab Bar 的显示/隐藏状态

**状态**
- 默认：底部 Tab Bar 显示
- 收起后：底部 Tab Bar 隐藏，图标变为 `↑`

### 5.2 底部 Tab Bar

**Tab 定义**

| 图标 | 含义 | 数据源 |
|------|------|--------|
| 💬 | 对话 | conversation |
| ⭐ | 收藏 | favorites |
| 🤖 | 模型角色 | roles |
| ⚙️ | 设置 | 设置面板（独立视图） |

**交互规则**
- 点击 Tab 切换当前视图
- 当前激活 Tab 高亮为 `#2563EB`，背景为 `rgba(37,99,235,0.06)`
- Tab 切换时列表内容平滑切换
- 设置 Tab 显示独立占位面板，内容待后续填充

### 5.3 列表区域

**列表结构（混合布局）**

```
[未分组头部] (当存在未分组条目时显示)
  条目卡片 1
  条目卡片 2
  条目卡片 3
[分割线]

[分组头部 ▶ 工作 (3)]
  条目卡片 A
  条目卡片 B
  条目卡片 C

[分组头部 ▶ 学习 (2)]
  条目卡片 X
  条目卡片 Y

[新建分组按钮]
```

### 5.4 分组头部组件

**结构**
```
[▶/▼ 箭头] [📁 图标] [分组名称] [(条目数)] [··· 更多按钮]
```

**交互**
- 点击箭头或头部区域：展开/折叠内部条目
- 点击 `···` 按钮：弹出上下文菜单
- 悬停：背景色加深 10%

**状态管理**
- 展开状态持久化保存（本次原型为内存存储，生产环境需持久化）
- 折叠时：内部条目隐藏，箭头旋转 -90°

### 5.5 条目卡片组件

**结构**
```
[图标区 32x32] [标题] [副标题] [··· 操作按钮]
```

**规范**
- 圆角：16px
- 悬停背景：`#F8FAFF`
- 图标区背景：`#EEF3FC`
- 标题字号：15px，字重 500
- 副标题字号：13px，颜色 #7F8FA4

**交互**
- 悬停：轻微背景色变化
- 点击 `···` 按钮：弹出操作菜单
- 右键点击整条：弹出操作菜单

### 5.6 上下文菜单

**分组模式**
| 操作 | 行为 |
|------|------|
| 重命名 | 弹出 prompt 修改分组名称 |
| 删除分组 | 确认后删除分组，内部条目移回未分组 |

**条目模式**
| 操作 | 行为 |
|------|------|
| 移动到分组 | 输入目标分组名，条目从原位置移除并添加到目标分组 |
| 移出分组 | 条目从当前分组移除，添加到未分组区域 |

## 6. 交互流程

### 6.1 新建分组
1. 用户点击列表底部 "新建分组" 按钮
2. 弹出 prompt 输入框
3. 输入分组名称，确认
4. 新分组添加至当前 Tab 的分组列表末尾
5. 分组默认展开

### 6.2 删除分组
1. 用户点击分组头部 `···` 按钮
2. 弹出上下文菜单
3. 用户选择 "删除分组"
4. 弹出确认对话框
5. 确认后，分组内所有条目移至该资源类型的未分组区域
6. 分组被移除

### 6.3 移动条目到分组
1. 用户右键条目或点击条目 `···` 按钮
2. 弹出上下文菜单
3. 用户选择 "移动到分组"
4. 弹出 prompt 提示输入目标分组名称
5. 精确匹配分组名后，条目从原位置移除
6. 条目添加到目标分组

### 6.4 切换 Tab
1. 用户点击底部 Tab 图标
2. 若点击 "设置" Tab，列表区域显示设置占位面板
3. 若点击其他 Tab，列表区域重新渲染对应资源类型的数据
4. Tab 激活状态变更

## 7. 数据模型

### 7.1 数据结构

```typescript
interface DataStore {
  [resourceType: string]: {
    groups: Group[];  // 分组列表
    ungrouped: string[];  // 未分组条目列表
  }
}

interface Group {
  id: string;  // 唯一标识
  name: string;  // 分组名称
  items: string[];  // 条目标题列表
}
```

### 7.2 支持的资源类型

| Key | 说明 |
|-----|------|
| conversation | 对话记录 |
| favorites | 收藏内容 |
| roles | 模型角色 |

### 7.3 初始数据示例

```javascript
{
  conversation: {
    groups: [
      { id: 'g1', name: '工作', items: ['项目方案讨论', '周报模板'] },
      { id: 'g2', name: '学习', items: ['React 教程'] }
    ],
    ungrouped: ['AI 对话：闲聊', '产品灵感记录']
  }
}
```

## 8. 视觉设计要点

### 8.1 字体与排版
- 主字体：系统字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`
- 无额外字体加载，确保加载速度

### 8.2 滚动条
- 宽度：4px
- 滑块颜色：`#D0D5DD`
- 圆角：20px
- 仅列表区域可滚动

### 8.3 分割线
- 颜色：`#F0F2F5`
- 用于分隔未分组区域和分组区域

### 8.4 微交互
- hover 状态：0.15s 过渡
- 折叠动画：0.25s ease
- 菜单出现：即时，无动画

|----------|------|------|

| 混合列表展示（分组+未分组） | ✅ | 核心内容组织 |
| 分组展开/折叠 | ✅ | 重要交互 |

## 10. 设计演进方向（后续版本）

- **数据持久化**：使用 localStorage 或 IndexedDB 保存用户数据
- **动画优化**：Tab 切换、条目移动时增加平滑过渡动画
- **键盘快捷键**：新增/删除/移动操作支持键盘快捷键
- **更多资源类型**：根据用户需求扩展资源分类
- **主题系统**：支持浅色/深色模式切换
